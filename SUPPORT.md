# Support

Support is provided through
[GitHub Issues](https://github.com/Pigbibi/TelecomMonthlyClaim/issues) on a
best-effort basis.

Before opening an issue, read the relevant guide, run the local lint and test
suite, start with workflow probe mode, and inspect redacted output. Include the
commit, runner type, connectivity mode, SMS provider, package preset, expected
behavior, actual behavior, and the smallest sanitized failure excerpt.

Never include phone numbers, OTPs, campaign URLs, order IDs, credentials,
private endpoints, SSH material, proxy URLs, screenshots, or carrier page
bodies.

The project cannot guarantee carrier eligibility, campaign availability,
benefit value, account status, or successful automation. Follow
[SECURITY.md](SECURITY.md) for vulnerabilities or sensitive-data exposure.
